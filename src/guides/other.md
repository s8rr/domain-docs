# Setting up other services with code-space.me

## Setting up records

Read the [domain file structure](../useful/domain-structure) and set up the records accordingly.

## Configuring your server

After the pull request is merged, configure your server (apache, nginx, etc.) to work with `subdomain.code-space.me`. If you are unsure how to configure your server, you can [create an issue](https://github.com/is-a-dev/register/issues/new/choose) for support.

You should also include `subdomain.code-space.me` in your ssl certificate to get rid of certificate errors.
